ANVI on your phone

  1. Install the ANVI app on your Android phone.
  2. Open it and tap Scan setup code from PC, then scan this code.
  3. Done. The app talks to Groq and Deepgram directly, so it works anywhere; PC actions reach this PC whenever it's on the same network (or Tailscale).

This code contains your API keys. Never share it or post a photo of it.
